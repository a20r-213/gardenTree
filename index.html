書き出し(OBSに入れるもの)

OBSでの使い方
  1. ゲームキャプチャを、上に出ている「拡大率」と位置に合わせて置く
  2. その上に「外枠」を置く(リンクのブラウザソース、またはPNG画像)。ゲーム画面の部分は透明です
  3. 各部品は、「リンクをコピー」したものをブラウザソースのURL欄に貼る。「ローカルファイル」のチェックは外します
  4. 幅・高さ・位置は、一覧に出ている数字を入れる(背景は透明になります)
  5. タスクメモは、ソースを右クリック → 「対話」で → / ← キー。探しものは対話画面でクリック(右クリックで減らす)

内容や配置を変えたら、変えた部品のリンクをコピーし直してURL欄を入れ替えてください。リンクにはこのファイルの場所が入っているので、ファイルを動かしたり名前を変えたりしたら作り直しです。進み具合や個数はOBSのブラウザ内に保存されます。

Stream Deck などから操作する

ボタン1つで「水やり」「タスクを進める」「アイテム+1」ができるようになります。小さな中継ツール(リレー)を、配信中だけパソコンで動かします。

ポート番号(ふつうは変えなくてOK)
設定のしかた
  1. 「リレーを保存」で overlay-relay.js を、好きなフォルダに保存します(Node.jsが入っている必要があります)。
  2. そのフォルダで、ターミナルから node overlay-relay.js を実行します。「起動しました」と出れば成功です。配信中は、この画面を開いたままにします。(.bat を同じフォルダに置けば、ダブルクリックで起動できます)
  3. 上の「この機能を使う」をオンにして、操作したい部品のリンクを、OBSに貼り直します。
  4. Stream Deck に「Webサイト」のアクションを置き、URL欄に下の一覧の「URLをコピー」で出したものを貼ります。「バックグラウンドでアクセス」にチェックを入れると、ブラウザが開きません。

リレーはこのパソコンの中(127.0.0.1)だけで動き、外からはつながりません。部品の名前で絞りたいときは、一覧のURLの ?part= 以降がその部品の名前です(名前を変えたらURLも取り直してください)。
