# 育つ木

ドット絵の木を、隙間時間に少しずつ育てるゲーム(試作版)。
放っておいても育ち、水やりやメモで少し早く育つ。枯れない。

## あそびかた

- **放っておく**: 時間がたつと、木が少しずつ育つ。約1週間で満開になる。
- **水をやる**: 画面下のじょうろをタップ。水は3時間で1杯たまる(最大3杯)。アプリを閉じている間もたまる。
- **木を触る**: 花びらと葉っぱが舞う。
- **メモを書く**: 右の「メモ」から。書かなくてもOK。1日1回だけ、水が1杯もらえる。書いたメモは「き録」で読み返せる。
- **植え直す**: 右上の歯車から。新しい種で、形のちがう木が育つ。メモは残る。

## ファイルの役割

| ファイル | 役割 | さわる頻度 |
| --- | --- | --- |
| `index.html` | 画面の骨組み(ボタンや小窓の置き場所) | たまに |
| `style.css` | 見た目(色・大きさ・ならび) | たまに |
| `game.js` | ゲームのしくみ(育つ速さ、水、メモ) | よく |
| `tree-art.js` | 木と動物のドット絵を描く部分 | ほぼさわらない |

`tree-art.js` は、配信用オーバーレイ作成ツール(overlay-maker.html)の「育つ木」のコードを、そのまま移したもの。

## 数字を変えて遊ぶ

`game.js` の一番上にある `CONFIG` の数字を変えると、ゲームのバランスが変わる。

| 名前 | 意味 | いまの値 |
| --- | --- | --- |
| `STEPS` | 満開までの段階の数 | 42 |
| `STEP_HOURS` | 放っておいたとき、1段階進む時間(時間) | 4 |
| `WATER_STEPS` | 水1杯で進む段階の数 | 1 |
| `WATER_MAX` | じょうろにためられる水の数 | 3 |
| `WATER_REGEN_HOURS` | 水が1杯たまる時間(時間) | 3 |
| `MEMO_WATER` | メモ(1日1回)でもらえる水の数 | 1 |
| `SEED_FIRST` | 最初の木の種(文字を変えると形が変わる) | roza |

## 時間を進めて確認する

アドレスの最後に `#debug` を付けて開き、右上の歯車を押すと、「+1日」「+3日」などのボタンが出る。
(例: `https://ユーザー名.github.io/tree-garden/#debug`)

## データの保存

育ち具合・水・メモは、使っている端末のブラウザの中に保存される。
スマホとPCでは、別々の木になる。ブラウザの閲覧データを消すと、リセットされる。

## 公開のしかた(GitHub Pages)

1. ファイルをリポジトリにアップロードする。
2. 「Settings」→「Pages」で、Branch を `main` にして保存する。
3. 1〜2分後に、`https://ユーザー名.github.io/リポジトリ名/` で開ける。
4. スマホでは、共有ボタンから「ホーム画面に追加」で、アプリのように使える。
