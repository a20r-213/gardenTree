育つ木

ドット絵の木を、隙間時間に少しずつ育てるゲーム(試作版)。 放っておいても育ち、水やりやメモで少し早く育つ。枯れない。

あそびかた
放っておく: 時間がたつと、木が少しずつ育つ。約1週間で満開になる。
水をやる: 画面下のじょうろをタップ。水は3時間で1杯たまる(最大3杯)。アプリを閉じている間もたまる。
木を触る: 花びらと葉っぱが舞う。
メモを書く: 右の「メモ」から。書かなくてもOK。1日1回だけ、水が1杯もらえる。書いたメモは「き録」で読み返せる。
植え直す: 右上の歯車から。新しい種で、形のちがう木が育つ。メモは残る。

これから(アイデア)
 満開のあとの動き(庭に植える、図鑑に残す)
 ゲーム内タイマー(勉強・作業の時間で水がたまる)
 木を触ったときの反応を増やす
 ドット絵の差し替え(じょうろ・アイコンなど)
 iOSアプリ化←Macないから無理そう…

 メモ
「枯れる」などのマイナス要素は入れない。続けるのがつらくならないことを大事にする。
毎日やらなくても育つ。やると少し得をする、くらいの強さにする。
